# Прогноз потребления в МО и раннее обнаружение шоков

**Команда: Timofey Usenko MISIS**

Решение для конкурса СберИндекса 2026, трек «Прогнозирование». Прогноз среднедушевых безналичных расходов в 2 016 муниципальных образованиях по 6 категориям на 1, 3, 6 и 12 месяцев, обнаружение шоков в первый же месяц и их объяснение по новостям.

- **Отчёт:** [reports/REPORT.pdf](reports/REPORT.pdf) (текст: [REPORT.md](REPORT.md)). Методы, результаты, обоснование выбора подходов и путь решения.
- **Лендинг:** https://metacortex67067.github.io/sberindex-forecast-shocks/ (исходник: [docs/index.html](docs/index.html)).
  
## Результат

Финальная модель: ансамбль из 9 вариантов STF (перенос сезонности с похожих рядов и национальных рядов СберИндекса) и foundation-моделей Chronos-2 и TimesFM 2.5. MAE на 12 096 полных рядах, скользящий бэктест 2024 г.:

| | h = 1 | h = 3 | h = 6 | h = 12 |
|---|---|---|---|---|
| Prophet | 599 | 626 | 735 | 870 |
| **Финальная модель** | **317** | **429** | **459** | **476** |
| изменение | -47 % | -31 % | -38 % | -45 % |

Модель точнее Prophet во всех режимах оценки и на всех горизонтах; прогноз прироста расходов на 2025 г. отличается от факта СберИндекса на 0,13 п.п. Лучший детектор шоков по сумме четырёх проверок: BOCPD. Подробности в отчёте.

## Запуск

Python 3.12 или 3.13, точные версии пакетов закреплены в `requirements.txt`.

```bash
pip install -r requirements.txt
bash run_all.sh
```

`run_all.sh` воспроизводит все таблицы, графики, отчёт и лендинг без GPU, около 1-1,5 ч на 2 ядрах. Шаги, которым нужен GPU (Prophet, foundation-модели, ARIMA, разметка новостей), по умолчанию берут готовые результаты из `results/` и `data/processed/llm_full/`. Полный пересчёт с GPU: `FULL=1 bash run_all.sh` с пакетами из `requirements-gpu.txt`, для разметки новостей нужно отдельное окружение из `requirements-llm.txt` (путь к его python задаётся в `PY_LLM`). Тот же запуск из Jupyter: `reproduce.ipynb`.

Публичная копия репозитория прогнана целиком в чистом окружении: все таблицы, прогнозы бэктеста, отчёт и лендинг совпали с исходным расчётом.

## Что где лежит

| путь | содержимое |
|---|---|
| `run_all.sh`, `reproduce.ipynb` | запуск всего расчёта по шагам |
| `configs/` | гиперпараметры: `models.yaml` (STF, ансамбль, Prophet), `changepoint.yaml` (детекторы), `news_llm.yaml` (языковая модель, фильтр новостей) |
| `src/sbershock/data/` | загрузка данных, панель «МО × категория × месяц», склейка объединённых МО |
| `src/sbershock/models/` | `stf.py` (STF), `foundation.py` (Chronos-2, TimesFM), `classic.py` (ETS, Theta, ARIMA), `prophet_model.py`, `ensemble.py` |
| `src/sbershock/evaluation/` | единый бэктест для всех моделей, метрики (MAE, R², MASE, кластерный бутстреп) |
| `src/sbershock/changepoint/` | 14 вариантов детекторов шоков и полусинтетическая проверка |
| `src/sbershock/news/`, `src/sbershock/features/` | разметка новостей (версия на правилах и версия с языковой моделью), признаки «МО × месяц» |
| `scripts/` | отдельные шаги расчёта, порядок задан в `run_all.sh` |
| `data/raw/` | исходные данные, список в [data/raw/README.md](data/raw/README.md) |
| `data/processed/` | панель, признаки, разметка новостей |
| `data/validation/` | 200 проверочных сообщений и эталонная разметка |
| `results/` | все таблицы (csv) и прогнозы бэктеста (parquet), включая результаты шагов на GPU |
| `reports/` | шаблон отчёта, графики, PDF |
| `docs/` | лендинг |
| `tests/` | тесты геопривязки новостей (`python -m pytest tests`) |
